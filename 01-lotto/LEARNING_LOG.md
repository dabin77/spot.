# 바이브 코딩 연습 01 — 로또 번호 추첨기

## 최초 요청

> HTML로 로또 번호 추첨기 만들어줘.

강의처럼 짧은 자연어 요구에서 시작하되, 생성 결과를 그대로 믿지 않고 기능을 확인했다.

## 확인하며 구체화한 요구사항

- 1~45 중 중복 없는 번호 6개를 추첨한다.
- 메인 번호와 겹치지 않는 보너스 번호 1개를 별도로 추첨한다.
- 번호 구간별로 공 색상을 다르게 표시한다.
- 번호가 순서대로 등장하는 짧은 애니메이션을 넣는다.
- 추첨할 때마다 기록을 누적한다.
- 기록을 지우는 기능을 제공한다.
- 모바일 화면에서도 번호와 버튼이 겹치지 않아야 한다.
- 키보드 포커스와 화면 읽기 알림을 지원한다.

## 직접 검증할 항목

1. 한 번 뽑을 때 숫자 7개가 모두 서로 다른가?
2. 메인 번호 6개가 오름차순인가?
3. 보너스 번호가 따로 표시되는가?
4. 여러 번 추첨하면 기록 수가 정확히 늘어나는가?
5. 기록 지우기 후 결과와 기록이 모두 초기화되는가?
6. 좁은 모바일 화면에서 가로 스크롤이나 겹침이 없는가?
